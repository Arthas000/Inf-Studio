# InFalsus Studio 0.8 — 操作与升级手册

基线：用户已在 Unity 6000.3.24f1 / URP 使用的 0.7。本包是源码更新；交付环境没有 Unity Editor 或 C# 编译器，未生成 Windows exe，未声称完成本版运行验收。

## 1. 升级

先在旧版保存需要保留的谱面，停止 Play、关闭 Unity，备份工程和歌曲工作目录。将更新包的 Assets 合并到实际 Unity 工程根目录；同名替换并保留 .meta。不要删除原目录，不要复制成 Assets/Assets，不使用早期 unitypackage。导入后左侧应显示 v0.8。

完整包仍是源码和 Assets，不包含用户现有 Packages/ProjectSettings；应在原工程中升级，不能直接把源码 ZIP 当作 Unity Hub 完整工程。

## 2. 红框提示是什么

`Line N: opaque text preserved.` 是解析器在提示：该行未被解释为已知的谱面调用，但原文本已保留。并不等于这些行丢失，也不等于 Unity 运行异常。

导入器写入的 `// source_note_id=...`、`// source_group_id=...` 等注释，旧版也逐行提示，造成大量无用列表。0.8 识别普通 `//`、`#` 注释后不再为它们提示，原文和换行仍保留。真正不支持的语句/参数仍能在“高级：未识别内容提示”中展开查看，默认折叠。没有删除未知的 icp_event 或来源资料。

## 3. 输入方式统一

所有主要数字输入（节拍细分、流速、参考BPM、音乐偏移、当前时间、空域网格、音符批量字段）及标题/曲师/等级、时序原语句，均采用：

**输入中只维护输入框草稿；回车或点击框外失焦时，验证并应用到内存。**

不会停顿0.28秒就提前应用。改完12再点外面，不会因控件已经失焦而拿旧4覆盖。支持Tab切换输入；不合法输入保持草稿并提示，不暗中按旧值当成功。Esc放弃正在编辑的输入。

点击宽度或方向等选项仍直接修改内存，不需要 Apply。点击框外用于提交数字的那一下不会穿透到场地创建一枚意外音符。高级 SOURCE 只支持一条语句，回车/失焦提交；不是多行代码编辑器。

**应用到内存 ≠ 保存文件。** Ctrl+S/全局保存才落盘；切难度保留草稿但不保存；停止Play或退出仍不保存。没有定时恢复写入。保存会先接收合法的待输入值，校验不通过则停止保存。

流速只保留一位小数：输入1.398应用为1.4；拖滑块也量化到0.1。播放速度不再输入，点击按钮依次为100% → 75% → 50% → 25% → 100%。音乐仍会随旧pitch方案变调，未加入保调拉伸。

## 4. 布局

难度侧签整体上移并缩短；未选64×77、选中78×91设计单位，保持右边对齐。选中的侧签最后绘制并优先命中，放大不再延伸到近端轨道。

全局编辑字体按视口设置为约13设计像素，输入框padding/高度一起调整。设置、歌曲、时序、音符面板的内容宽度受限，长说明换行，横向大滚动条不再用于弥补过宽的布局。单行输入框内部仍可水平滚动长文件路径。

播放/暂停改为分数底框左下小梯形中的透明图标按钮，无额外灰色矩形、无“播放”文字。右上曲绘和进度条保持原位置。播放时仍隐藏编辑控件，保留游戏HUD/中央COMBO/进度/播放图标。

## 5. Sky group：决定头框和头音

同一个非负 group 的 SkyArea，按开始时间排序，只给第一条画头括框和播放 Sky hit。后续哪怕中间断开数秒，也不产生新的头。若同时间开始，按稳定源ID选择一条，保证结果确定。

没有group或group=-1的旧段暂按独立未分组对象处理，不把所有-1合成一大组。已有导入谱面加载时不自动改组，尊重原文。

新建Sky默认分配现有最大非负group+1（空谱从0开始）。但在提交这次编辑的同一撤销事务中，会检查前后连接：

- 前段结束时间与后段开始时间一致（容差0.001ms），且尾/头的横向区间重叠或接触：后段继承前段group。
- 时间一致但横向不重叠：不继承，新建仍保留新组。
- 修改后由不连接变成连接：即时继承。
- 修改前段，接上已存在后段：后段同样继承，可沿连接链传播。
- 从连接改成不连接：不拆组、不自动生成新group。
- 同时存在多个可接前段：选择开始时间最近、再按源ID确定的前段；不擅自合并无关组。

自动改组与端点修改只占一个撤销步骤；取消拖动也回滚组号。单独手动编辑group字段是明确覆盖，不因一次只改group的动作立即被连接规则改回。

头音和持续音是两件事。相同group中存在时间空隙时，持续音会在空隙停止，后续段开始时仅恢复持续床，不补Sky hit。两个持续音总线（地面/空域）继续独立。

设置中Sky头音选择“每组首段”或“关闭头音”，不再用“每条都有hit”作为正常选项。

## 6. 点立得状态修正

完成Sky/Hold/Tap/Flick后，保持当前放置类型与点立得模式。下一次右键打开的是类型菜单，不是Home；新创建音符虽被选中，也不会因此强行打开选区操作菜单。主动回到选择工具后，有选区仍使用删除/复制等选区菜单。

Hold已经选择头时间、Sky已选择头时间或头X但未完成时，右键按下立即取消当前草稿并消费此次按键，不会同时开菜单。下一次右键才打开类型菜单。

“不创建”立即清空未完成草稿并解除活动工具，留在点立得模式；“退出”解除工具并回Home。Ctrl复选、Alt把手、段选、复制剪贴取消规则不变。

## 7. 空中音符的地面投影

新增轻淡的平面投影，不依赖实时灯光阴影。直接使用已裁到空域范围内的Sky/Flick网格，将顶点的Y替换为地面上方极小偏移，X和Z保持不变。

因此归一化0的空域左边界，投影恰在中央四轨的左边界x=-2；归一化1对应x=2。不会投到两侧轨，也不会通过屏幕平移假装落地。Flick弯刃的装饰深度同样有对应投影，但仍不是长条持续时间。

投影不参加拾取、判定或计分。设置中可关闭“空中音符的地面投影”。当前是程序化淡色，仍需在实际Unity画面中检查透明顺序与可见度。

## 8. 空域吸附 1/N 与精度

设置 → “空域坐标网格 1/N（Sky / Flick）”。N允许1～4096。N=20为5%，N=3为三等分。横向网格独立于每拍细分N，不改变音乐时间。

每个位置直接计算k/N，不反复累加已经取整的步长。边界始终包含0和1。

重新检查用户Notes.zip五份本体明文：13,284个空域中心/宽度/分母字段全部是整数形式。它们存的是有理坐标，不是显示归一化后的小数。因此不能拿原文件“0位小数”把1/3舍入成0，也不能拿track速度的长小数位数作为空域精度标准。

新建中心=1/3、宽度=10%可写成 `x=10, split=30, width=3`；不是 `x=33.3333333333, split=100`。已有对象只有本次编辑的端点参与编码；旧分母若能以有限十进制表示本次结果就保留，若会循环则选共同分母。未动的尾端、时间、额外参数、原文精度均不改。

UI可显示约33.333333%，这只是显示，源里使用10/30。明确手输SOURCE继续保留用户文本；没有对全谱做小数清洗。

`Fixtures/08_InputEmpty.spc`：输入12，保持焦点确认网格尚未改；Enter后生效。再输入7，点外部生效；停止输入几秒不应提前应用。流速1.398→1.4。播放按钮循环倍率。

`08_GroupHeadsAndGaps.spc`：group7中间有间隙但只一个头框/头音；持续床在空隙暂停。group8另有自己的首段。

`08_ThirdsAndProjection.spc`：左界空域投影落在中央地面左界，Flick也有淡投影；新建N=3网格音符后查看整数分子/分母。

## 10. 独立Windows版本

本包附带 Windows 本地文件夹/文件对话框、MP3/OGG加载和真正BuildPlayer入口。**没有附带已经编译好的exe。** 详细操作见 `BUILD_WINDOWS.md`。

在你实际Unity工程中，通过菜单本地构建后，输出才包含`InFalsusStudio.exe`和Data/DLL等依赖。不要只移动exe。主线程外只调用原生Win32对话框，不从后台线程调用Unity API。MP3/OGG解码使用file URI，不上传音频、不运行下载程序。

这些Player新路径未在交付环境实机运行；本地Build成功也不代替启动exe、打开中文路径歌曲、播放、保存重开和取消对话框的验收。
