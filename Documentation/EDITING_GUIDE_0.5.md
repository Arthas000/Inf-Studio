# InFalsus Studio 0.5 操作手册

## 1. 本轮不改什么

你已验收的相机、四条中央轨、两条侧轨、判定面、Flick 固定参考高度、四难度、音乐加载和右上素材层叠保持原样。UI 和实际材质无需重新配置。本轮添加/修改的是指针规划、空域可达边界、HUD 数字和元数据交互。

0.5 的实际 Unity 导入/编译/键鼠验收仍须在本机完成；不把0.4实机运行截图当0.5证明。

## 2. 播放时左键不会暂停

在三维场地点击已有音符，只改变选择；点击空白没有 transport 操作。播放期间不启动把手拖动、主体拖动或点立得放置，也不显示放置预览。请先按 Play/Space 主动暂停再写谱。

显式操作（播放按钮、空格、滚轮浏览、定位、切换难度/歌曲）仍可能暂停，这是用户主动改变 transport，不属于误点场地。窗口失焦、音频到末尾仍保留原保护。

左Ctrl门控、右键按下立即出菜单、0.5秒子菜单、宽键自动左移、网格与滚轮一档一格都保留。

## 3. 自动指针 v2

无 Flick 接近/执行时，取当前有效 Sky 左右边界中点。多个同时 Sky 使用可达区间的交集；完全重复的同区域段不视为冲突，但记录/物量不去重。交集为空时单指针不能满足，采用确定的预览退化策略并在 Song 显示冲突。

单 Flick：在其时刻前靠近中心（中心不在当前 Sky 内但 Flick 范围与 Sky 有交集时，选交集中可达位置），执行对应方向短划，再回到当前空域中心。

同时间全左 Flick：从最右到最左依次扫过；全右相反。混合方向使用连续可视序列，并明确标注 mixed/constraint，而不保证这是游戏能同时 Exact 的输入。

默认 SwipeMs=100ms、短划位移0.055、ApproachMs=140ms、ReturnMs=85ms，集中在 Core/AutoplayCursor。它们是演示参数，不是推定的游戏判定窗。

为避免“指针还没扫到另一枚、音符就全部消失”，在 Auto cursor 与 Clip played notes 开启时，同时间组尚待接触的 Flick 会短暂保留在判定面，经过它之后才隐藏。原始时间、曲率、横坐标、宽度和分数均未改；关闭自动指针后恢复原先按事件时刻隐藏。不是官方判定模拟。

所有位置由绝对歌曲时间求值；暂停/拖时间/循环不累积前一次运动误差，也不劫持真实鼠标。

### Enigma FBD 24070ms

该组是两枚16码左 Flick，中心为5/24和22/24，活动 Sky 的左界此时约0.1666965，右界1。规划从22/24向5/24扫过，并在每个实际帧重新按当前正在收窄的 Sky 夹住指针。不是把 Sky 中心固定到0.5，也不是两套独立短划互相抢指针。

## 4. 硬边界

中央四轨的整体左/右边界分别是X=0/100（文件归一化0/1），世界X=-2/+2，不包含两侧键轨。

用户实测 `skyarea(45916,1,12,2,1,12,2,2,1,5363,256)` 左边界为 `1/12-(2/12)/2=0`。以这一实测和其右侧镜像建立编辑硬边界。

鼠标新建靠边空域会向内放到能够完整容纳其宽度的位置；不会把宽度偷偷缩窄。主体整组横移受整组公共可达范围限制；端点移动保留该端宽度；L/R边界不能超出0/100。相应高亮标尺会跟随实际有效落点。移动时间不主动重写未参与的原始X。

手动语句/导入仍保留越界字段，Inspector给出AIR BOUNDS警告。显示裁剪覆盖 Sky 填充/边缘、Flick装饰/边缘/发光；拾取来自裁剪后实际三角形，不能选到屏幕外看不见的一截。编辑/左Ctrl状态显示两条空域 reach 辅助线。

黄色针尖X被限制；紫色指针的装饰翼与黄色光晕不是判定点，未以它们的外包盒重新缩小可达范围。

## 5. 曲目信息编辑

- 曲绘左键：执行Open folder，与顶部入口相同，支持已确认的Enigma主/附加音频处理。
- 曲名/曲师左键：当前字段出现文本框。
- 等级数字左键：只编辑0..99整数；MIN/EVO/ULT/FBD不可改。
- Enter或OK提交；Esc或X取消。输入时全局空格/字母快捷键不穿透。

右上曲绘和难度素材及正常显示位置保持原版0.4布局。编辑等级时的小输入条会暂时盖住附近SPEED位置，提交/取消后恢复。

显式提交写入 `infalsus.studio.json`，并在源 `song.json` 存在且字段可识别时同步：title.default、artist.default，与旧default完全相同的已填写翻译，以及当前Difficulty掩码对应的两处Rating/LevelSectionIndicator。独立翻译、空翻译、曲目ID、音频/曲绘路径、谱面数据、其他难度和纹理ID均不改。

写入采用原文token范围替换，源JSON里的64位整数不经过浮点反序列化回写。每次保存前后字节均保存到 `.ifstudio/MetadataHistory/<时间_GUID>/`；成功也有 `.bak`。目录中无源song.json时只更新自己的manifest。未知结构/非法数字拒绝，不去猜字段。

这是单文件原子替换加双文件恢复记录，不是跨文件断电事务。中断或外部编辑竞争时，按照明确错误信息检查MetadataHistory备份，不把失败说成成功。

普通Save/切难度仍只写工作谱和manifest；不会顺便同步来源chart JSON或二进制文件。建议在自己的歌曲工作目录操作，备份歌曲目录再测元数据编辑。

## 6. SCORE与物量显示

数字、两个分组符和发光边距合并预算，画在底框的实际内部区域而不是PNG透明尾部。仍是原创七段数字，不附游戏字体。

Song面板显示Tap/Hold/Sky/Flick分类模型值。五个已提供谱面按已知note/BPM几何语义匹配时，标注MEASURED REFERENCE MATCH，并可在左上显示MAX=100000000+实测总连击。等价分母/格式化/注释不会破坏匹配，但编辑相关数据后不再当作已测量；未知记录不升级为确认。

新谱或其它难度只有PROVISIONAL COUNT。首音符之前SCORE是0；之后缺少真实score记录继续显示横杠。新的拟合不是已认证tick时刻，更不是中途分数公式。导入的score observations仍是独立hash绑定实测回放。

请阅读COUNT_FINDINGS_0.5：两组不同公式不仅总数一样，在这五张谱的每条Hold/Sky上也一样，因此36秒原片还不能唯一消除模型差别。

## 7. 本机验收

在工程副本合并更新后，先跑Run CSharp Core Checks。再播放Enigma FBD跨24070ms；检查不误暂停、双Flick扫动、指针不离开收窄Sky。暂停并关网格定位45916ms，拖左边界到最左。用左Ctrl检查边界辅助线；用原文录入一个越界Flick，确认有警告而源文本仍在。

点击曲名改一次、Esc取消一次，再改一次Enter保存；重开工程核对显示与song.json，其它字段用文件diff确认不变。四个难度分别检查等级数字与固定缩写。开启Inspector播放，确认旧GUILayout问题没有回归。

新增菜单Check v0.5 Air Mesh Clipping会执行实际C#网格裁剪测试；Check Running Camera Landmarks验证标定不漂移。日志报错需保留第一条完整堆栈。
