# InFalsus Studio 0.9 — 组浏览、固定原速音效、背景与窗口

以本手册为准；原本点立得/复选/Alt把手/显式保存保持不变。基线0.8已由用户实际使用，本轮0.9源码尚未在交付环境运行Unity或C#编译，实际窗口、素材和声音要在本机验收。

## 升级

保存需要保留的谱面，停止Play，关闭Unity并备份工程。更新包的Assets合并到工程根，不删除旧目录，不变成Assets/Assets，保留所有.meta。普通更新不改Packages/ProjectSettings。仍从Tools/InFalsus Studio/Open Demo Scene运行，版本显示0.9。更新包不是可直接添加到Hub的完整Unity工程。

## 当前组

顶部顺序：谱面流速 → **当前组（数量）/上一个/下一个** → 基准BPM → 音乐延迟 → 当前时间。输入组号后Enter或点框外提交到浏览状态，不改任何Sky的group。选择一条SkyArea会把当前组切到它的组；批量选中以主选中对象为准。点地键/Flick不会把组自动清成0。

上一个、下一个以**当前播放头时间**寻找同组SkyArea的开始时间，分别严格小于/大于当前时间。跳转会暂停、选中该对象并显示原起点。已经站在一段起点，再按下一个就是更晚的那段；不循环回第一条。组内为空、当前之前/之后没有对象都有提示。相同时间的多个段采用稳定源ID的第一个；下次跨到更晚的时间，不在同时间戳内反复循环。

现有文件可能有未设置组或-1。它们不被聚合成一个组；选中时可显示-1/0成员，手动组号只接受非负整数。

**这是浏览不是吸附编辑。** 源起点即使有小数或不在当前网格上，跳转仍精确到原时间，暂停锁格不会立刻把它移走。后续滚轮重新按网格浏览。跳转会取消未完成的放置草稿，但不会写文件、改组号或改变放置工具。

## key音保持原速

播放速度100%/75%/50%/25%影响歌曲播放与谱面时间推进；key样本一律pitch=1。攻击的实际样本长度不随倍率延长；触发间隔依旧跟谱面。持续音循环也以原速播放，但要持续到长条的实际结束，因此25%时同一个长条的持续床会保持更长时间。

这是样本速度与谱面时钟分离，不是让音乐也保调。歌曲仍沿用既有pitch变速；改播放倍速不改独立的“谱面流速”倍率、不改track、BPM或谱面原始时间。暂停/定位/换倍率会撤销旧排程并重建，循环相位是恢复策略，不承诺无缝音乐或持续音循环。

## 播放按钮

SCORE左下的空置区域增加了淡色梯形轮廓和悬停反馈。整个较大的外接区域都可点击，箭头本身仍是原尺寸。普通场地点击仍不暂停；播放时仅保留必要HUD/进度/播放控制的策略不变。

## 背景

设置 → 背景/窗口：选择PNG/JPG，或点“附件示例”使用内置的 `4615631595253104_ordirehv_bg.png`。可清除、隐藏、调整亮度。更换后立即预览，不写歌曲数据。

默认是**等比铺满并居中裁边**，不留下图片内部白边、不拉伸图案。附件真实尺寸2048×1024（2:1），而校准视口16:9，因此默认两侧各裁约5.56%。需要整幅图全部保留并填满，可勾选“拉伸完整图片”，但此模式会改变图片比例。没有承诺2:1图片在16:9中既完整、不变形又无留白三者同时成立。

背景是相机前远端的单独几何层，先画背景、后画轨道和音符，不是遮住note的GUI图片，不加碰撞体/拾取。相机位置、透视和轨道尺寸都不动。

外部文件限制32MiB、单边8192及32MP；会在解码前读PNG/JPEG尺寸。只载入图片，不载入可执行插件或材质脚本。外部图片保留路径引用，不自动复制到歌曲目录，迁移电脑后可能需要重选。

## exe窗口

设置中有720p=1280×720、1080p=1920×1080、2K/QHD=2560×1440、4K=3840×2160，也有自定义宽高。实际最小960×540；建议不低于1280×720。

- 普通窗口：有系统边框，支持拖动四边/四角。
- 无边框窗口：去掉标题栏与可见边框，仍有原生边缘缩放命中区；不是把全屏改个名字。
- 独占全屏：使用Unity ExclusiveFullScreen；硬件不支持的尺寸由系统/Unity适配。
- 无边框全屏：覆盖桌面的FullScreenWindow，不支持从边缘缩小；需先返回窗口模式。

F11可恢复1280×720普通窗口。只在独立Windows程序实际应用尺寸/模式；Editor内仅提示，请自行调整Game视图，不会把Unity主窗口改成无边框。

校准视口仍保持16:9。上述四个预设可以完整铺满；自由拖成其他宽高比会按现有相机逻辑留边，背景铺满的是有效游戏视口，不把场地拉变形。窗口OS/多显示器/DPI/全屏切换为本轮新代码，尚需Windows实机验收。边框命中只作用于本进程的UnityWndClass，不操作其他窗口。

## 保存偏好

图片、显示模式和窗口尺寸立即影响当前显示，但仅全局Save成功后记住到本机 `Application.persistentDataPath/presentation.v09.json`。退出不自动保存偏好；拖边缘改变的实际尺寸也在全局Save时记住。该文件与歌曲谱面独立，不把显示设置伪装成SPC事件；外观保存失败会单独提示，不能误报谱面保存失败或已回滚。

无歌曲时请先新建/打开谱面并正常另存，再用Save记住外观。本版没有新加自动保存按钮；沿用用户的唯一全局保存习惯。

## Coldsea未知事件

附件明文有1479行，末尾是三个合法bpm事件，不存在2954～2956物理行。2954～2956恰好对应本编辑器JSON导入后“3行头+1475个音符各两行+3个事件”的位置；这是有依据的推断，而非读取了你本地工作文件。

可直接Load SPC打开附件明文。需要保留现有歌曲工程时，在“时序事件”点 **从配对明文补入 BPM/拍号…**，选择正确的未改同难度明文。程序先核对头部及所有已知音符语义，再只补缺少的bpm行；冲突或谱面不匹配全部拒绝。已有未知包装不删除，音符不改动，一步撤销，Ctrl+S之前不落盘。已改过音符的工作谱可能无法通过配对检查，这是避免把别首歌的timing混进来的保护；应人工核对时序，不能强制跳过。

详情见 `COLDSEA_UNKNOWN_EVENTS.md`。建议先另存工作副本，不在游戏安装目录直接试验。
