# InFalsus Studio 0.2 — 制谱交互与更新手册

日期：2026-09-21。基于用户已经在 Unity 6000.3.24f1 运行成功的 0.1.1；本次新增代码仍需在该 Unity 环境编译、运行验收。请勿把旧版本运行截图当成新版本测试结果。

## 1. 这次改变什么，不改变什么

相机、中央四轨、侧轨接缝、判定面、场景文件以及三份 Shader 均保持原样。本版没有重做场地，也没有引入原游戏素材。新增的是运行时编辑交互、文件可靠性与本地音频工作流。

Flick 修正：**同一纵深/距离，宽度变化只影响横向跨度，不影响视觉高度；距离变化仍有正常透视缩放。** 旧版用真实音符屏幕宽度乘 0.20，已停止使用。新版以同一空域平面、同一深度的一单位参考横段求出像素尺度，再乘 `flickHeightUnits=0.40`。默认保留原先 12/24 宽的参考形状，不再让 2/24 变成极扁，也不让 24/24 加倍变高。

所有 Flick 网格顶点仍在固定空域 Y。端帽横向偏斜对于极窄 Flick 另设上限，防止上边界回折；上限仅改变横向偏斜，不降低高度。装饰后边缘不代表持续时间。

## 2. 从已经跑通的 0.1.1 升级

1. 先在旧版把正在编辑的谱面另存到工程外；停止 Unity 的 Play，再关闭 Unity。给工程做一次备份，特别是你自己修改的源码、标定 Profile 和素材。
2. 推荐解压 `InFalsusStudio_v0.2_Update.zip`，把其中 **Assets 文件夹合并到现有工程根目录**，同名文件选替换，保留 `.meta`。最终是 `你的工程/Assets/InFalsusStudio/...`，不是 `Assets/Assets/...`。**不用删除整个 Assets，也不用删除原来的 InFalsusStudio 文件夹。** 补丁保留未涉及的场地、Shader、场景与参考谱面。
3. 重新打开工程，等脚本导入；顶部菜单 `Tools → InFalsus Studio → Open Demo Scene`，切 Game，16:9，点击 Unity 的 Play。顶部应显示 `UNITY EDITOR 0.2`。

完整包 `InFalsusStudio_Unity_Prototype_v0.2.zip` 也可以使用：复制其中的 `Assets/InFalsusStudio` 合并替换即可。两种下载不需要重复安装。这次不提供旧的 `.unitypackage`，不修改 Packages/ProjectSettings，不要求安装 Input System 或 Cinemachine。

新项目也要先用 Unity 创建 URP 工程，再复制 Assets；这个源码包本身不是可直接加入 Unity Hub 的完整工程。

## 3. 推荐先做的一个完整闭环

打开 `Opening ~1826` → 在紫色空域主体上单击 → 拖动 `R` 或 `TR` 改一个端点的右边界 → 松开 → `Ctrl+Z` → `Ctrl+Y` → `Save As` 保存成新文件 → `Load SPC` 读回新文件。

检查撤销是否一步完成、读回后端点是否一致、开头窄端仍然是 1%、原文件有没有被覆盖。三维修改使用的是原始 SPC 字段，不是把网格顶点反向拼成一份新谱。

第一次正式制谱前，建议先加载 `Fixtures/Editing_Sandbox.spc` 做操作练习。它是人工合成的编辑器测试样本，不是原曲，也没有通过游戏本体播放兼容认证。

## 4. 新建和放置

顶部 `New` 建一张 `chart(130,4)` 空谱，保留当前音频。已有未保存修改会尝试写恢复副本；在 Unity Editor 内还会询问是否继续。之后修改 Inspector 里的 chart 头可以设置起始 BPM、拍数。

| 工具 | 快捷键 | 场地操作 |
|---|---|---|
| 选择 | Q | 点选、拖动、框选、把手编辑 |
| Tap | 1 | 点击实际地面/侧轨放置 |
| Hold | 2 | 按下选起点，拖到终点再松开；仅点击使用默认拍数长度 |
| SkyArea | 3 | 在空域平面拖出首尾位置和时间；仅点击使用默认拍数长度 |
| 左 Flick（黄色、16） | 4 | 点击空域平面放置瞬时音符 |
| 右 Flick（绿色、4） | 5 | 点击空域平面放置瞬时音符 |

顶部 `New ground width` 选择中央键的 1/2/3/4 轨宽。起始 lane 是最左覆盖轨，超出中间四轨时拒绝放置并提示；不会悄悄缩成窄键。两侧固定一轨宽。

`Air width n/24` 是新建空中音符的归一化宽度；`Length n beats` 是单击建立 Hold/Sky 的默认时长。已有音符可在 Inspector 改原始 split，拖动会使用该音符自己的 split，并不强制改成 24。

放置时线框是预览，松开才提交。反向拖出 Hold/Sky 时首尾会按时间排序；Sky 的横向首尾也随之交换。按 Esc 放弃本次放置。放好后按 Q 返回编辑。

## 5. 单选、多选、框选、重叠拾取

点击音符选择，主体拖动会移动所选集合；Shift 点击加选，Ctrl 点击切换该音符是否选中。空白处拖出框选矩形；Shift 框选追加，Ctrl 框选切换框中对象。框选依据已经生成的可见网格三角形，不是仅检查头部中心。

`Pick Both / Ground / Air` 限制场地拾取和框选。遇到重叠对象，点击后按 Tab 在该点的候选里循环。Ctrl+A 选中当前 Ground/Air 筛选下的全谱音符；全谱对象可能远多于当前可见部分。

一次连续拖动只写入一次撤销记录。鼠标移动预览从按下时的文档重算，不在上一帧结果上继续累计。松开提交，Esc/窗口失焦取消；越界或非法预览被拒绝，保留最后一个有效预览。整组选中里任意地键放不下，整次预览被拒绝，而不是缩宽或只移动一部分。

选择集中的一个对象是“主选中对象”；三维把手及原始字段 Inspector 对应它。其他选中对象会高亮。**原始数值输入框的 Apply 只改主对象，不是批量套值。** 原始字段只有按 Apply 才进入谱面文档。

## 6. 每个把手的含义

| 对象/把手 | 改变什么 | 不改变什么 |
|---|---|---|
| Tap/Flick 的 MOVE，或音符主体 | 时间和横向位置；主体可拖整组选中 | 原宽度；Flick 方向 |
| Hold H | 开始时间 | 结束时间、轨道、宽度 |
| Hold T | 结束时间 | 开始时间、轨道、宽度 |
| 中央 Tap/Hold 的 L/R | 起始侧或结束侧覆盖边界 | 对面的边界；时间 |
| Sky H/T | 对应端点的时间和中心 X | 另一端时间/位置；该端宽度 |
| Sky L/R | 起点左/右边界 | 起点另一侧；终点和时间 |
| Sky TL/TR | 终点左/右边界 | 终点另一侧；起点和时间 |
| Flick L/R | 瞬时横条的左/右边界 | 对面边界、判定时间、方向、高度样式 |

侧轨不提供宽度把手，必须单宽；其拖动与选中使用真正的斜面。Flick 主体点击到了向后延伸的弯刃，拖动仍以原始基线的判定时间为锚，不会把装饰尾缘误当成另一个音符时间。

未完成的长条默认裁去已过去部分。需要编辑已过去的头部时，关闭 `Clip played notes` 或把播放头向前挪。

## 7. 吸附、微调、镜像、剪贴板

`Snap` 控制拍点与空域 X 吸附。`1/N beat` 的 N 为每拍分割数，例如 N=4 是四分之一拍，不是四分之一小节。可循环选择 1、2、3、4、6、8、12、16、24、32。拖动时 Alt 临时关闭拍点和空域 X 吸附；地面轨道宽度始终是离散轨宽。

空域中心按自身 split 吸附；边界可到半个原始格，以免固定另一侧时导致无意义跳动。不同首尾 split 分别计算，原始数据没有整体重采样。

| 快捷键 | 含义 |
|---|---|
| Ctrl+C / Ctrl+X | 复制/剪切选中的音符，保留额外参数和相对时间；不会顺便剪切选中的 BPM/track |
| Ctrl+V | 最早复制音符对齐当前播放头的吸附时间 |
| Ctrl+D | 在选区末尾之后一格复制一份 |
| M | 横向镜像：地面覆盖区、左右 Flick 方向，以及 Sky 左右缓动一起镜像 |
| Delete | 删除选中；chart 头受保护 |
| Ctrl+Z / Ctrl+Y 或 Ctrl+Shift+Z | 撤销/重做 |
| ← / →（有选中） | 地键移动一轨；纯空中选中移动 1/24；混合选中按一中央轨的横向步长同步 |
| ↑ / ↓（有选中） | 时间增加/减少当前的一格；Shift 为一拍，Alt 为一毫秒 |
| 箭头（无选中） | 向前后移动约一帧；Shift 为 100 ms |
| 滚轮（场地空白） | 移动播放头；Shift 更细 |
| Esc | 先取消正在进行的手势；无手势时退出选择 |
| Space / F1 | 播放暂停 / 隐藏界面 |

数字输入框获得焦点时，全局编辑快捷键不会穿透到谱面；先 Apply，再点击场地或用 Esc 退出输入。

粘贴默认给原有非负 Sky group 做一致的新 ID 映射，避免新副本与原段共用标签；Inspector 可关闭此选项。没有 group 或为 -1 的段不会被凭空分组。这只是编辑器的复制策略，**不宣称 group 在游戏中一定表示连段判定。**

## 8. 空域链、独立缓动和宽度诊断

主选中 Sky 时，Inspector 中 `Left/Right × Linear/SineOut/SineIn` 可以批量设置所选 Sky 的相应边界缓动。`Continue primary Sky at its tail` 以现段尾部的时间、中心、宽度、split 创建一个显式后续直线段；原段不被切开、不被重写。其他已知 group/额外参数保留。

`Select same explicit group` 选择相同非负 group；未分组的 -1 不会被视为一个巨大组。本版**不自动传播相邻端点修改**。需要接缝保持连续，可多选整条移动；单独改端点后，应检查另一段的对应端点。

Inspector 同时显示中点宽度与**整段连续最小宽度**。对于三种已知缓动，程序解出宽度导数的内部零点并比较首尾与内部候选，而不是仅看20个网格采样。最小值为负会警告左右边界中途交叉，保留原始文件，不偷换边界或删除事件。

原生 Sky 不是任意贝塞尔曲线。此版未加入任意曲线控制点、自动平滑接链或任意位置无损分割；直接分成两个相同 ease 的段通常会改变形状。

## 9. 停流/倒流怎样编辑

游戏预览仍按 `S(t)=∫track_speed dt`，不乘 BPM。一个三维深度可能对应多个时间，零速可能对应一整段时间。默认三维拖动优先使用最接近当前选中事件/上一帧拖动的时间分支，并在有歧义时提示。

`Time layout (no track)` 将显示纵深改成单调时间布局，**不更改文件中的 track，也不调整相机**。这是处理复杂段落的编辑模式；回到游戏预览时关掉它。

`Timeline / wave` 打开底部单调时间视图。上方音频波形，下方六条地轨和一条 Sky/Flick 行。点击空白定位，点击对象选中，横向拖动对象改变时间，可以拖整组选中。Ctrl+滚轮缩放时间范围，普通滚轮平移播放头。它不受 track 暂停倒流干扰。

底部时间视图是覆盖层，打开后遮挡部分下方场地，不会缩放或重设相机。需要干净三维视野时关闭它或按 F1。

## 10. BPM、滚速、音频、书签与循环

在 Inspector 的 Timing 区可输入正 BPM 或任意有限 track speed（含0和负数），添加到当前吸附播放头。附近 chart/BPM/track 条目可选入原始字段区修改/删除；初始 chart 头不可删除。未知事件、特殊 BPM 语义仍保留原始文本，未宣称全部本体兼容。

`Scroll` 是视觉滚速，`Playback` 是音频/时间倍速，二者独立。Space/顶部播放按钮是应用内部播放；Unity 顶栏的 Play 是整个程序的运行开关，不要混淆。

Audio 加载：
- WAV：本地读取 RIFF PCM8/16/24/32 或 float32，默认不引用 UnityWebRequest；有256 MiB文件与64M样本上限。
- Unity Editor 中的 OGG/MP3：通过 Unity 自带 AudioImporter 导入用户选中的文件。外部音频会复制到 `Assets/InFalsusStudioUser/Audio`，不改原始音频；已经在工程内的文件直接复用。资源设置为 Decompress On Load 以读取波形。更新本编辑器目录不会删掉这个用户音频目录。
- 已导入的 AudioClip：可直接拖到 Inspector 的 Imported AudioClip 槽。
- 打包的独立 Player 默认支持上述 WAV；OGG/MP3 动态加载仍需要可选模块或后续解码器，不能拿 Editor 的导入能力当成 Player 能力。

波形每帧处理一块数据，完成前显示 Building waveform。波形是幅值峰值缩略图，不是高精度音频分析。现有0.5倍速通过 AudioSource.pitch 同步减速，会变调；未加入保调时间拉伸。

底部 A/B 设置循环端点，Loop 开关重复试听，Mark 加书签，Next 跳下一个书签。循环依赖重新调度，**不是无缝音频循环保证**。

## 11. 保存、备份、恢复、会话

Ctrl+S / Save：第一次选择新路径，之后保存该工作副本。Ctrl+Shift+S / Save As：另选副本。不能直接覆盖本次 Load SPC 的原文件；同一路径会拒绝，防止误改原始数据。重新加载工作副本后，第一次保存仍需要选择不同路径，这是当前保守策略。

写入同目录临时文件后再替换目标，已有目标保留 `.bak`，并回读核对字节。文件系统不支持替换时会提示失败，不先删除旧目标。未知事件、参数、原有行序、未改动数值拼写与换行仍保留。

同名 `.spc.studio.json` 是编辑会话，记录音频路径、音频偏移、播放头、循环、书签、显示模式、滚速与吸附。它不是游戏谱面，不要合并进SPC。Unity 工程迁移后外部音频路径可能需重新指定。

脏文档每约60秒、且自上次恢复后有变化时，尝试向 `Application.persistentDataPath/Recovery` 写单独SPC；退出/换谱也尝试恢复。拖动未提交期间不写预览快照。Console 会记录具体恢复路径。它是尽力恢复，不等于断电保证，也不会保存未 Apply 的输入框文字。

内部 SourceId 在当前文档会话内稳定，删一行不会让后面的选中对象变成别人；ID 不写入 SPC，重新加载时重新分配。撤销栈最多200个事务。

## 12. 本轮验收与已知边界

已在交付环境运行：355项独立 Python 数学/资源检查，88项新增数学/结构/基线对照检查，21份C#/Shader源码的有限词法检查。**没有在该环境执行 C# 编译或 Unity。** 真正的 C# 回归通过 `Run CSharp Core Checks` 执行；运行相机/各宽度 Flick 通过 `Check Running Camera Landmarks` 检查。

本版还不是全部完工的专业制谱器：未做大量真实键鼠回归、Windows构建、音频设备延迟测量与大谱性能压测；没有游戏判定/计分、原版材质/HUD、完整beam/lane语义、自动平滑空域链、无缝循环与保调拉伸。选区接近相机近裁面、窗口缩放中途、复杂交叉透明网格、多时间分支等需要后续实机用例。发生问题时保留操作步骤、第一条完整错误和当前SPC副本，不以乱改相机解决。

## 13. 素材交接

可将贴图/材质按 GroundTap、GroundHold、Side、FlickLeft、FlickRight、SkyBody、SkyEdge、Track、JudgeLine 分类，保留原文件名，附已知对应关系。PNG/TGA需保留透明通道；有图集时带切片信息；有材质时同时提供 Shader 名称、纹理槽、混合/深度设置的截图或数据。此轮不要求等待这些素材，所有逻辑和网格可先使用当前占位外观。只有确认可以使用的资源才接入，未提供的资源不虚构；不要将无权分发的原游戏素材提交到公开仓库。
