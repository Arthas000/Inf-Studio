# InFalsus Studio 0.7 — 选区、即时调参、浮动剪贴与界面更新

适用现有 Unity 6000.3.24f1 / URP 工程。基线0.6已由用户实际测试；本次新增C#及Shader使用路径未在交付环境编译、运行。不能把下述实现说明视作Unity实机验收结果。

## 1. 更新

先在旧版本按 Save/Ctrl+S 保存需要保留的谱面、元数据；停止Play、关闭Unity、备份Unity工程和歌曲目录。解压更新包，将其中 **Assets 合并到工程根目录**，替换同名文件并保留.meta。不删除旧目录、不复制成Assets/Assets、不使用历史unitypackage、不替换Packages/ProjectSettings。

打开 Tools → InFalsus Studio → Open Demo Scene，进入Play。左侧显示v0.7。Full ZIP是源码和文档，不是可直接用Unity Hub打开的完整Unity工程。新项目先建Universal 3D工程再导入。

## 2. 这次的基本分工

**Ctrl：增选/取消单个音符。Alt：解锁主体及把手拖动。** 以前左Ctrl拖动的操作已经替换。Windows上左右Alt均可；非Windows修饰键后备仍需各平台实测。

普通点击选择一枚；Ctrl点击切换其选中状态。Shift点击继续兼容切换选择。选中同类型多个音符时出现批量参数面板，混合Tap/Hold/Flick/Sky时不弹参数面板。混合选择仍可复制、剪贴、镜像、删除、对齐。

播放中不编辑或多选，不被场地左键误暂停。主动点暂停/Space才能修改；进度条是明确定位操作，拖动它会暂停。

## 3. 即时参数，不再逐项 Apply

Tap/Hold宽度按钮、Flick左右方向、Sky左右形状：点击后下一轮安全的UI布局立即修改内存与预览，无需Apply。

数字字段停止输入约 **0.28秒** 后自动提交；Enter可立即提交。这样输入负号、小数点或替换数字的中间态不会立即损坏数据。无效/越界数值不改谱，状态栏提示原因；Esc放弃尚未提交的数字。普通参数改变时不重排未涉及的字段，原始时间词法、不同split和未知参数保留。

同类型批量修改只改你操作的字段；空白框表示选区中原来值不同，不会把空白写进每个音符。Tap可统一宽度/轨道，Flick可统一时间/宽度/方向，Sky可统一左右形状、起始或结束宽度，另有“统一首尾宽%”。开始/结束时间是绝对时间；改一个不自动平移另一端。越界或零长等批量改动整体拒绝，不部分提交。

快速输入数字后点击其他选项，会把完整有效的待输入数值一并提交到内存，不要求额外Apply。切换选区/开始编辑/复制前会先尝试提交有效字段，不能用旧字段覆盖另一批音符。

**这些都是RAM编辑，不是文件保存。只有 Save/Ctrl+S 才写入全部工程草稿。** 切难度保留内存，不自动保存；退出不保存。高级原始SPC语句单独展开，Ctrl+Enter明确提交原文到内存，允许非网格时间和精度；同样不写盘。

## 4. 段落选择

左侧“段落选择”按钮 → 在场地选择开始网格 → 点击结束网格。

Tap/Flick按原始时间，Hold/Sky按 **结束时间** 落在闭区间内选中；两次点击可前后反向，系统取较小/较大端。不是“与区间有重叠就算”，也不是按长条开始时间判断。

完成后成为普通选区，Ctrl点击继续加选/取消。未完成时可以滚轮/拖进度条浏览；右键按下或Esc取消并恢复开始段选前的选择，不同时唤出菜单。

## 5. 复制与剪贴：拿在手上的浮动预览

选中一枚或多枚，右键按下立即出现选区菜单。在“复制”或“剪贴”上松开右键。

- 复制（Ctrl+C）：保留原谱，显示半透明预览。
- 剪贴（Ctrl+X）：原选中对象仅暂时隐藏，源数据没有删除；显示移动后的半透明预览。
- 持有预览时滚轮和右上进度条都能浏览，不取消预览；鼠标回到场地后预览跟随目标高亮网格。
- 预览把最早一枚的开始时间对齐鼠标目标；其他音符保留相对时间间隔和所有横向形状。它不是横向任意平移工具。
- 左键点击目标网格才落下。复制新增对象；剪贴移动原对象并保留ID。整次落下形成一次撤销。
- 右键 **按下** 或Esc取消；复制不新增，剪贴原位恢复，选区恢复，撤销栈不增加。
- 右键取消这次不会同时打开菜单。需要菜单再按一次。
- Ctrl+V可再次拿起上次复制内容；Ctrl+D也进入复制预览，不立即粘贴。

未完成Hold/Sky的分步放置同样右键取消。草稿期间不允许另一个编辑命令悄悄改源；保存或显式播放会先结束/取消未落下草稿，不会把半条预览写进文件。

## 6. 对齐与网格

右键选区菜单有删除、镜像、剪贴、复制，以及网格开关/点立得入口。**只有网格开着才显示“对齐网格线”。** 在该按钮上松开右键，选区Tap/Flick时间分别取最近网格；Hold/Sky首尾独立对齐，再由两个绝对时间求duration。任一长条被压成零长则整体拒绝，提示提高细分。

复制本身保留间隔，所以仍可能出现1ms差别。例：130 BPM原头115/231ms，复制最早头到231ms，得到231/347ms；显式对齐后是231/346ms。复制和对齐是两个各自可撤销的操作，不把复制默认变成重写每条时间。

左侧细分输入 **N** 表示1/N拍，不再只能循环预设；支持整数1..1024，Enter确认。极密网格同毫秒去重，渲染有有限工作上限。1/12的1/4、1/2等共同拍位仍沿用特殊颜色；其他细分为浅青，小节/整拍颜色不改。滚轮一档一格，向上前进，向下后退；沿用原来的设备输入单位设置。

所有新段选/预览/点立得时间选择共享投影网格落点：最近网格按实际屏幕横截线比较，高亮与落点一致。Alt只解锁编辑，不能绕过已开启的时间网格。手输语句仍是独立无吸附通道。

## 7. 界面重新分布

- 左上SCORE字母下移，数字和辅助信息保持各自区域。
- 顶部中间：谱面流速、基准BPM、音乐延迟、当前时间。数字Enter提交；时间也可点定位。
- 基准BPM是编辑器 **视图归一化**，默认取chart头；0恢复跟随头部。它不更改谱面BPM、节拍网格、物量、音乐速度。
- 音乐延迟正数=音乐晚开始。内部project offset存负数（audio_ms=chart_ms+offset）；这不是确认原游戏有同名SPC事件。Enter只改RAM，Save后持久保存。
- 右上歌曲HUD下新增进度条；原底部长进度条移除，只保留细状态栏。波形详细时间轴仍可开关。
- 左侧外露图标+文字：播放、设置、时序事件、Auto、段选、保存、打开歌曲、撤销/重做、波形、歌曲信息、相机、帮助/语言、退出。左侧另有细分N和播放百分比输入（25..200，Enter）。
- Settings收起默认值、网格/小节/音效选项、测试预设、导入导出及其余高级功能。旧的Tools功能没有简单删掉。
- 右侧Min/Evo/Ult/Fbd纵向侧签使用本轮四张资源。选中项增大，最后绘制，并优先接收重叠区点击。曲绘/右上难度底图不重画。
- 默认主编辑UI中文，小图标程序绘制；Help支持中英切换，技术诊断/部分高级字段保留英文。系统字体运行时读取，不附字体文件。
- 播放时隐藏参数面板、侧签、设置等编辑控件；只保留SCORE、中央COMBO、右上曲目信息、进度条、播放/暂停和游戏场地本身。暂停后按原状态恢复。
- 退出先提示，1秒内再点一次确认。Unity Editor里停止Play；未保存修改丢弃，不自动写文件。第一次点击的提示也出现在按钮上。

## 8. 音频中断修补

旧版音乐使用默认优先级，而key音设置80且允许96声道。在Unity真实声道不足时，较低优先级源可能被虚拟化为静音；这是源码中可确认的风险路径，尚未在交付环境复现用户录音。

本版音乐强制priority=0（最高），持续效果48，攻击效果160。读取当前numRealVoices，给音乐和持续床留预算，攻击池最多20，总FX最多24；预算用尽丢弃额外效果，不挤占音乐。相同样本同一时刻合用声道，仅影响试听叠加音量，不改变note/物量/score。

Sky头音默认“连通段落首段”：同一时刻首尾足迹有接触/重叠才相接，不只按group或时间粗暴并段；完全重复的段不叠头音。头框与头音共用同一连接判定。独立不相接空域即使同时开始仍是独立头。地面Hold和Sky两个持续床仍可同时播放。

Settings和菜单 **Check v0.7 Runtime and Difficulty Assets** 提供音乐priority、isVirtual、真实声道数和FX丢弃量。若音乐仍断，请记录同一段谱面、时间、该诊断和Audio Profiler；不把优先级风险修补说成所有设备上已听音通过。

## 9. 头框、指针与打击效果

每个几何连续Sky区域首段的开头有两侧小括框，后续接段没有。活动状态/已经过去的头部按原时间规则隐藏；不会为加括框改变SPC或计数。

黄色针与原空域同高，末端约到视口从底部75%的位置，即从顶部约四分之一处，不再一直通向消失点。相机与空域高度没变。

Auto开启且播放时显示简约程序化效果：中央Tap青蓝色短亮束，左侧淡紫/右侧品红；Hold持续波动的短极光条；左右Flick在对应外侧高端闪光与少量粒子；Sky当前范围上有不同亮度的紫色小三角。暂停/定位时不补发历史闪光。

这些是轻量视觉预演，不是原游戏粒子系统的提取或一比一复刻。单帧有128个效果对象预算，渲染不影响判定、计分或音频。关闭Auto同时关闭指针跟随/已判定隐藏/击打音和视觉反馈，按键选择编辑不被游戏指针劫持。分数栏仍可查看当前时间的候选物量预览，不成为手动游玩判定器。

## 10. 最小实机验收

先运行 Tools/InFalsus Studio/Run CSharp Core Checks，所有旧测试与新的Release07均要执行。再Play运行Check v0.7 Runtime and Difficulty Assets；确认4张难度侧签载入、音乐priority0、实际预算合理。

Fixtures/07_Batch_Properties：Ctrl多选同类，点击宽度立即变；混选隐藏面板；Alt拖/普通点/右Ctrl行为区分；Ctrl+Z恢复。改后不保存停止Play，重开恢复磁盘旧内容；保存才保留。

Fixtures/07_Selection_Copy_Range：选1000..2000，应选4个对象（Tap1000、Flick2000、Hold尾2000、Sky尾1500）；Hold尾2500不选。Ctrl取消一个，再复制预览、拖进度条、右键取消；源与撤销不变。剪贴同样验收。

Fixtures/07_Copy_OneMs_Alignment：原115/231复制到231后看347，再对齐346；连续撤销两次准确恢复。

Fixtures/07_Connected_Sky_Heads：1000段与2000中间段连接，第二段无头框/头音；2000右边独立段仍有；3001有1ms间隙，另起一段。

Fixtures/07_Audio_Dense_Disconnected：先载一首连续音乐，再载该松散谱面；密集段必须持续听到音乐。FX掉额外声道可见计数，但音乐不应virtual。

Fixtures/07_Hit_Feedback：依次Tap三色/Flick两向，4500..8000地面Hold与Sky同时持续，检查VFX+两条持续声、暂停停干净、恢复不补旧攻击。
