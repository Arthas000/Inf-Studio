# InFalsus Studio 0.3 — 点立得操作手册

**适用：由0.2升级的Unity 6000.3.24f1工程。新增代码仍需真实Unity编译与键鼠验收。** 已有相机、地面/侧轨、Flick高度及材质未重做。此文覆盖旧0.2中普通拖动、Alt跳过吸附、左键拖出长条的规则。

## 1. 更新与入口

保存副本 → 停止Unity Play → 关闭Unity → 备份 → 更新ZIP的Assets合并至工程根，同名替换并保留meta → 打开工程等待编译 → Tools / InFalsus Studio / Open Demo Scene → Play。

顶部应为 `UNITY EDITOR 0.3`。不删旧文件夹，不使用旧unitypackage，不替换Packages/ProjectSettings。完整包不是能直接在Hub打开的全工程；新用户先创建URP工程再合并Assets。

## 2. 右键环形菜单：所有确认都靠“松开右键”

### 一级

在不被工具栏/Inspector覆盖的场地区域**按住右键约0.28秒**。一级菜单包含“点立得”和“网格线”。移动到目标按钮后松开右键：点立得只进入该模式；网格线切换显示与时间吸附。不会自动连开下级菜单。

### 点立得类型菜单

已经进入点立得模式后，**再次长按右键**，出现：Tap、Hold、SkyArea、Flick、不创建、退出、网格线。

在Tap/Hold/Sky/Flick上直接松开右键：使用该类型保存的默认值，关闭菜单并开始放置。选择后连续生效，不用放一个重新选一次。Q或“不创建”停用放置；“不创建”保留点立得模式，下次右键还是类型菜单。“退出”同时停用工具并回到一级模式。

所有层级在空白处松开都不执行任何菜单动作，也不更改上次类型、默认值、模式或网格。空白释放只收起这次显示的菜单；下一次长按重新打开该模式的菜单。左键无菜单确认作用。

### 宽度/方向子菜单

| 类型 | 保持右键并悬停0.5秒 | 松开右键的结果 |
|---|---|---|
| Tap | 1 / 2 / 3 / 4轨宽 | 更新Tap默认宽度，并切换Tap放置 |
| Hold | 1 / 2 / 3 / 4轨宽 | 更新Hold默认宽度，并切换Hold放置 |
| Flick | 左（黄）/右（绿） | 更新方向，并切换Flick放置 |
| SkyArea | 不展开 | 直接释放使用当前Sky默认值 |

子菜单中心**就是原先对应类型按钮的中心**。展开前后都保持右键按住；鼠标此时在子菜单中心空白区，继续移到具体宽度/方向，再松开才执行。离开类型按钮会重新计算悬停时间。右键未松开时不改变工具或文档。

Tap/Hold宽度彼此独立。lane0、5无条件使用单轨宽，中央四轨才使用所选宽度；在中央放不下会提示拒绝，不偷偷缩窄。Flick子菜单没有宽度项，现有宽度由源参数或左Ctrl把手调整；新建Flick暂沿用25%初始宽。

## 3. 左Ctrl解锁编辑

普通左键点击只选中；Shift点击切换对象，空白拖动框选，Tab循环同一点的重叠候选。已有选中音符不再普通一拖就移动。按住**左Ctrl**才出现并启用把手，也才可拖主体。右Ctrl不解锁；Ctrl+C/V/Z等键盘命令仍可正常使用。

左Ctrl也限制底部Timeline的音符拖动。地面/侧轨沿原始几何移动；Sky/Flick使用原来正确的空域平面。宽度把手只改那一侧，另一侧保持不动。

松开左鼠标完成一次拖动；如果先松开左Ctrl，则立即在最后一个有效预览处结束并提交一次，后续鼠标移动不再写文档。Esc或窗口失焦取消未提交拖动，不留下中间状态。一次拖动只占一条撤销记录。

正在使用放置工具时，按左Ctrl临时进入选中/把手操作；切换到Q Select可以只查看和编辑现有音符。开启 `Clip played notes` 时，过去的头部仍可能不可见，需要关掉裁剪或把播放头往前移。

## 4. 分步放置：不再按住左键拖到底

| 类型 | 连续的左键点击 |
|---|---|
| Tap | 选择高亮时间线+地面轨道 → 提交 |
| Hold | 选择起始时间+轨道 → 浏览并选择结束时间 → 提交 |
| Flick | 选择时间 → 空中标尺选择X → 提交 |
| SkyArea | 起始时间 → 起始X → 结束时间 → 结束X → 提交 |

**右键只选菜单，左键只在菜单关闭后推进放置步骤。** 时间选择通过实际六轨地面的高亮线确定；Sky/Flick同时显示该时刻的空域横线，避免两套时间坐标偏移。X阶段只看空中横向标尺，不存在可调Y。

点击确定端点后，滚轮浏览/拖播放头不改变已锁定的时间和X。结束时间必须严格晚于开始，不自动交换头尾。确认最后一步前只是预览，没有半条SPC；完成最后一步才单次提交。Esc取消本条但保留工具，可以接着重放；没有进行中的预览时Esc返回选择工具。

切换类型、退出/不创建、切换网格或细分、Apply新默认值、播放/隐藏界面、失焦会取消未完成预览。空白右键释放不会取消它。先保存正式提交的谱面；未完成预览不是可恢复的数据。

## 5. 时间网格：显示即吸附

`Beat grid (snap)`、右键菜单里的网格开关控制同一个状态。开启后，放置和改变时间的鼠标拖动都必须落在线上；Alt不能绕过。关闭后鼠标自由选时间但仍写整数毫秒。**原有音符不会因开关网格或修改拍数被自动重排。**

顶部 `1/N beat` 为每拍细分N，循环选择现有选项。Inspector的Timing中第一格为BPM、第二格为每小节拍数；`Apply BPM + meter to chart header` 修改初始值，`Add BPM+meter`在当前拍点增加段。

例如 `chart(120,4)` 配每拍细分4：每拍500ms、一格125ms、一小节2000ms。每小节拍数改成3后，整拍/细分时间不变，小节起点改成每1500ms。新的正BPM段按其事件时间重新建立局部网格和小节起点，省略拍数继承前值。这是本编辑器的可解释网格策略；不是对所有特殊本体BPM事件语义的证明。

小节起点为较粗蓝线，整拍按奇偶区分红/绿，细分为细灰蓝线。当前准备选取/移动的落点为黄色高亮，并显示时间。渲染、底部Timeline、高亮、放置共享同一个时间候选，避免画线和吸附各算各的。

时间由 `段起点 + 格号 / 每拍细分 × 60000 / BPM` 直接计算，最后一次四舍五入，0.5向远离零方向。不能把115.384…先取成115再不断累加。130BPM、四细分从0的前几格是0、115、231、346、462……；第四拍1846ms。一百万个细分后的时间115384615ms，而不是115000000ms。

整组沿时间移动时，先从手势开始的原文算目标，再把各已移动的头/尾吸到真实线。这样115ms后的一格能落在231而非230。因为每个落点单独最终取整，持续时间/相邻间距可能相差1ms；跨BPM段按目标网格处理。网格太粗导致头尾合并时拒绝整个预览并提示细分，不悄悄删除音符。只调宽度不改时间。

## 6. 横向网格与数值精度

0与100分别是**中央四轨整体**的左右边界，不包括斜侧轨。默认X网格间隔5%，可在顶部 `X grid step %` 设0.1～100，再按Apply defaults。刻度间隔不整除100时仍显示100端点。

新Sky宽10%，默认左右Linear；顶部 `Sky width %` 与 `Sky L/R` 可以修改之后新建的默认值。Sky本版不设径向子菜单，避免每次选择过多层级。已有音符的左右缓动仍在选中Inspector修改，不受新建默认值影响。

Sky/Flick选X或按左Ctrl拖把手时，显示固定高度、当前时间的一维标尺。活动刻度为绿色，旁边显示X / 100。横向网格与时间网格是不同维度；关闭节拍线不会关闭横向刻度吸附。精细的任意X仍可直接修改语句。

SPC中每段原有split保留；显示0～100只是编辑坐标。新建默认写split100。修改边界采用十进制定点运算，生成值最多10位小数并去掉尾零，避免1.01499999999式尾数。原始未改的字段不重新格式化。

因此，只改宽度后仍看到旧的1846.153846…时间是有意保护原文，并不表示本次宽度吸附失败。需要改变这个时间时，左Ctrl拖动到高亮线即写整数；直接Apply SOURCE text则保留你输入的精度。曲率/高度不因坐标显示格式改变。

## 7. 原始语句、撤销和保存

选中对象，Inspector的整行文本框中编辑SPC，点击 **Apply SOURCE text (no snap)** 提交；各参数文本框的Apply也是显式无吸附路径。一次只允许一条语句，不用整段粘贴覆盖全文；已知或未知调用都可保留，但须保持有效chart头。未知事件可存而不一定会渲染。

只替换指定源行，保留稳定ID、其他行、换行/BOM和未触及token。Ctrl+Z/Y恢复语句和编辑，不把网格改动扩散到全谱。

保存沿用0.2工作副本、临时写入替换、.bak与回读检查。新会话侧车version3保留网格、细分、X间隔、Sky默认值、Tap/Hold默认宽度以及旧音频/循环/书签；兼容加载version2。工具类型不在重开工程时自动开始放置，以免误触。会话侧车不是SPC。
